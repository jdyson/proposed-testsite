# proposed-testsite

A clickable proposal for the next GigaLabPro: one client desk at $20 a month.

It keeps proposals, invoices, and client email, and adds four jobs people already pay other apps for: a starting recipe, a rewrite, a meeting-note follow-up, a social trio from work you already did, and a five-item week plan. Drafts are shaped on this page from what you type so you can try the flow without an API key. They are not a live model.

This is a separate repository from `test-site`. Nothing here is copied from Zapier’s writing or from the products in their roundup.
